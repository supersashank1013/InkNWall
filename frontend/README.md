# InkNWall 🎨

Poster marketplace for IITM students.

## Tech Stack
- Frontend: React + Vite + Tailwind
- Backend: Spring Boot
- Database: PostgreSQL
- Storage: Cloudinary

## Features
- Google Login (@smail.iitm)
- Poster upload (Admin)
- Premium posters
- Cart system (per user)
- Orders + Email system
- Admin logs

## Setup

### Backend
Configure:
backend/src/main/resources/application.properties

### Frontend
Run:
npm install
npm run dev
